# Assignment 2.1 — First HTML Page

## 1. Objective

The objective of this assignment is to create a basic HTML webpage using a title, headings, HTML comments, and proper indentation.

## 2. Introduction

HTML stands for HyperText Markup Language. It is the standard markup language used to create webpages. HTML elements define the structure and content of a webpage, such as headings, paragraphs, links, and images.

## 3. HTML Code

Create a file named `index.html` and write the following code:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- Set the title of the webpage -->
    <title>My First Webpage</title>
</head>
<body>
    <!-- Main heading of the webpage -->
    <h1>Welcome to My First Webpage</h1>

    <!-- First subheading -->
    <h2>About Me</h2>
    <p>Hello! I am learning HTML and web development.</p>

    <!-- Second subheading -->
    <h2>My Education</h2>
    <p>I am a student and I enjoy learning new technologies.</p>

    <!-- Third subheading -->
    <h2>My Hobbies</h2>
    <p>My hobbies include reading, learning computer skills, and exploring technology.</p>
</body>
</html>
```

## 4. Explanation of the HTML Elements

1. `<!DOCTYPE html>` — Declares that the document uses HTML5.
2. `<html>` — Defines the root element of the webpage.
3. `<head>` — Contains metadata and the page title.
4. `<title>` — Sets the title displayed in the browser tab.
5. `<body>` — Contains the visible content of the webpage.
6. `<h1>` — Defines the main heading.
7. `<h2>` — Defines subheadings.
8. `<p>` — Defines a paragraph.
9. `<!-- comment -->` — Adds a comment that is not displayed on the webpage.
10. Proper indentation — Makes the HTML code easier to read and maintain.

## 5. How to Run the Webpage

1. Open Visual Studio Code.
2. Create a file named `index.html`.
3. Copy the HTML code above into the file.
4. Save the file using `Ctrl + S`.
5. Open the folder containing the file.
6. Double-click `index.html` to open it in a web browser, such as Google Chrome.

## 6. Expected Output

The browser should display the following content:

### My Education
